Exemplo de JSON para Importação LCI

O arquivo JSON deve conter uma lista de processos com os campos abaixo. Fontes (source) não têm entradas; processos (process) referenciam outras fontes via inputs.

{
  "processes": [
    {
      "id": "sun_input",
      "name": "Radiação Solar",
      "type": "source",
      "unit": "J",
      "uev": 1.0,
      "description": "Energia solar incidente",
      "inputs": [],
      "output_amount": 5000000.0
    },
    {
      "id": "rain_input",
      "name": "Chuva (Energia Química)",
      "type": "source",
      "unit": "J",
      "uev": 18000.0,
      "description": "Energia química da chuva",
      "inputs": [],
      "output_amount": 150000.0
    },
    {
      "id": "fertilizer_input",
      "name": "Fertilizante NPK",
      "type": "source",
      "unit": "J",
      "uev": 12000000.0,
      "description": "Insumo não renovável",
      "inputs": [],
      "output_amount": 20000.0
    },
    {
      "id": "crop_production",
      "name": "Produção de Milho",
      "type": "process",
      "unit": "J",
      "uev": 1.0,
      "description": "Processo de cultivo",
      "inputs": [
        { "process_id": "sun_input", "amount": 1.0 },
        { "process_id": "rain_input", "amount": 1.0 },
        { "process_id": "fertilizer_input", "amount": 1.0 }
      ],
      "output_amount": 1.0
    }
  ]
}
CampoTipoObrigatórioDescrição
idstringSimIdentificador único do processo
namestringSimNome legível
typesource | processSimFonte primária ou processo intermediário
unitstringSimUnidade da quantidade de saída (ex: J, kg, L)
uevnumberSimUnit Emergy Value (sej/unidade)
inputsarraySimLista de entradas ([] para fontes)
descriptionstringNãoDescrição opcional
output_amountnumberNãoQuantidade produzida (padrão: 1.0)
